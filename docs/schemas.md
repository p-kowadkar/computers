## `exposures` (version 1)

One exposure. Some plates carry several exposures. `center_distance`, `edge_distance` (cm on the plate) and `lim_mag_apass` are relative to the position queried, so they are null in tile tables; use `plate_dist` and `limiting_mag_local` in `measurements`. `median_colorterm_apass` diagnoses the emulsion (below -1.13 red, above -0.53 blue, else yellow; exactly 0.0 is suspect). `plate_class` is empty in `queryexps`, so it is null until filled from `/plates`.

Primary key: `exposure_id`. Fingerprint: `cc61eed97dc256e4`.
